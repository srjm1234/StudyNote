# 项目实战：简易图书馆

> **来源**：`D:\study\C#1\WinForm\0804-作业\简易图书馆`

最简版的图书登记：`List<string>` 存书名，实现**添加、删除、遍历显示**。适合练习集合的基本操作。

---

## 1. 整体思路

```
List<string> 存书名 → 添加（Add）/ 删除（Remove）→ 遍历显示（foreach）
```

## 2. 核心代码

```csharp
public partial class Form1 : Form
{
    List<string> list = new List<string>();   // 图书集合

    // 添加图书
    private void button1_Click(object sender, EventArgs e)
    {
        list.Add(textBox1.Text);
    }

    // 删除图书
    private void button2_Click(object sender, EventArgs e)
    {
        list.Remove(textBox1.Text);
    }

    // 遍历显示（当前版本只显示最后一本）
    private void button3_Click(object sender, EventArgs e)
    {
        foreach (string s in list)
        {
            textBox1.Text = s;
        }
    }
}
```

> 💡 集合三操作：`Add` 添加、`Remove` 删除、`foreach` 遍历，是集合使用的三大基本操作。

## 3. 图书数据模型（Book 类）

```csharp
class Book
{
    public string Title { get; set; }    // 书名
    public string Author { get; set; }   // 作者
    public int Id { get; set; }          // 编号
}
```

> 💡 用类代替字符串可以存更多信息（作者、编号），这是从「字符串集合」到「对象集合」的升级。

## 4. 改进建议（对比正式项目）

| 现状（简易版） | 改进方向 | 对应完整版 |
|---------------|---------|-----------|
| `List<string>` | `List<Book>` 对象集合 | 图书管理系统 Book 类 |
| TextBox 显示 | ListBox / ListView 展示 | 图书管理系统 DataGridView |
| 内存存储，重启丢失 | 写入文本文件 | `06-文件与IO操作` |
| foreach 只显示最后一条 | `listBox1.Items.Add(s)` 显示全部 | 见下方示例 |

### 改进示例：用 ListBox 显示全部图书

```csharp
private void button3_Click(object sender, EventArgs e)
{
    listBox1.Items.Clear();
    foreach (string s in list)
    {
        listBox1.Items.Add(s);   // 全部显示
    }
}
```
