# 循环结构

> 循环用于重复执行一段代码。本篇覆盖 for / while / do-while / foreach 四种循环及循环控制。

## 循环 4 要素

| 要素 | 说明 |
|------|------|
| **初始化语句** | 设定循环变量的初始值，仅在循环开始时执行一次 |
| **判断条件** | 每次循环前检查，为 `true` 继续循环，为 `false` 退出循环 |
| **循环体** | 被重复执行的代码块 |
| **迭代器** | 更新循环变量的步进语句（如 `i++`），决定方向与计数 |

## for 循环

重复次数**可设定**的循环。

```c#
for(初始化语句; 判断条件; 迭代器)
{
    // 循环体
}
```

**执行步骤：**

1. 执行初始化语句（仅在第一次循环前执行一次）
2. 判断条件：为 `true` 则执行循环体，为 `false` 则退出循环
3. 执行迭代器（通常为 `i++`）
4. 回到步骤 2

```c#
for (int i = 0; i < 10; i++)
{
    Console.WriteLine(i);   // 输出 0~9
}
```

## while 循环

当**不确定具体循环次数**时使用。

```c#
int i = 0;
while (i < 10)
{
    Console.WriteLine(i);
    i++;
}
```

## do-while 循环

**先执行一次循环体，再判断条件**（至少执行一次）。

```c#
int i = 0;
do
{
    Console.WriteLine(i);
    i++;
} while (i < 10);
```

**while vs do-while 区别：**

| 对比 | while | do-while |
|------|-------|----------|
| 判断时机 | 先判断后执行 | 先执行后判断 |
| 最少执行次数 | 0 次 | 1 次 |
| 适用场景 | 条件优先 | 至少执行一次（如密码登录校验） |

## foreach 循环

用于**遍历集合或数组**中的每一个元素，无需关心索引。

```c#
int[] nums = { 1, 2, 3, 4, 5 };
foreach (int num in nums)
{
    Console.WriteLine(num);
}
```

> foreach 只读遍历，不能在遍历中修改集合长度；需要索引时用 for。

## 循环控制语句

| 关键字 | 作用 |
|--------|------|
| `break` | 立即终止整个循环 |
| `continue` | 跳过本次循环，进入下一次 |
| `return` | 结束整个方法 |

详细用法见 [[02-流程控制/循环控制语句]]。

## 嵌套循环（预习）

循环语句中再写循环语句，外层循环每执行一次，内层循环执行完整的一轮。

```c#
for (int i = 0; i < 3; i++)       // 外层：行
{
    for (int j = 0; j < 3; j++)   // 内层：列
    {
        Console.Write("* ");
    }
    Console.WriteLine();
}
// 输出：
// * * *
// * * *
// * * *
```

> 典型应用场景：打印九九乘法表、打印图形（矩形/三角形）、多维度遍历。详见 [[02-流程控制/循环嵌套]]。
