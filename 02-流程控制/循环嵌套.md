# 循环嵌套

## 概念

- 在循环体内部再写一个循环，就构成**循环嵌套**，可以嵌套多层。
- 最经典的是**双层 for 循环**。
- 外层循环每执行一次，内层循环执行**完整的一轮**。

## 执行逻辑

- 只要判断条件成立，就要执行循环体。
- 可以把内层循环看作是外层循环的**循环体**。
- 执行顺序：外层循环第 1 次 → 内层循环全部执行完 → 外层循环第 2 次 → ……

## 代码示例

```csharp
for (int i = 0; i < 5; i++)
{
    // 内层循环的开始
    Console.WriteLine("内层循环的开始");
    for (int j = 0; j < 5; j++)
    {
        Console.WriteLine($"i={i}, j={j}");
    }
    // Console.WriteLine(j);  // ❌ 错误：外层无法访问内层变量
    Console.WriteLine("内层循环的结束");
}
// Console.WriteLine(i);  // ❌ 错误：此处无法访问循环变量
```

## 注意要点

- 初始化变量名称**不可以相同**（如 `i` 和 `j` 必须不同）
- 外层循环**不可以**访问内层循环的变量
- 内层循环**可以**访问外层循环的变量
- 总执行次数 = `外层次数 × 内层次数`

## 典型应用

### 打印矩形

```csharp
for (int i = 0; i < 3; i++)       // 外层：行
{
    for (int j = 0; j < 3; j++)   // 内层：列
    {
        Console.Write("* ");
    }
    Console.WriteLine();
}
// * * *
// * * *
// * * *
```

### 打印九九乘法表

```csharp
for (int i = 1; i <= 9; i++)
{
    for (int j = 1; j <= i; j++)
    {
        Console.Write($"{j}×{i}={j * i}\t");
    }
    Console.WriteLine();
}
```
