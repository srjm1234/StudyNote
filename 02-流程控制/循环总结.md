# 循环总结

> 07-08 循环复习与总结。本文为 [[02-流程控制/循环结构]] 的精简复习版，适合快速回顾。

## 循环 4 要素

| 要素 | 说明 |
|------|------|
| **初始化语句** | 设定循环变量的初始值，仅在循环开始时执行一次 |
| **判断条件** | 每次循环前检查，为 `true` 继续循环，为 `false` 退出循环 |
| **循环体** | 被重复执行的代码块 |
| **迭代器** | 更新循环变量的步进语句（如 `i++`） |

## 四种循环对比

| 循环 | 适用场景 | 特点 |
|------|----------|------|
| `for` | 重复次数可预知 | 初始化 / 条件 / 迭代器集中在一个括号 |
| `while` | 不确定具体循环次数 | 先判断后执行，可能一次都不执行 |
| `do-while` | 至少执行一次 | 先执行后判断 |
| `foreach` | 遍历数组 / 集合 | 只读遍历，无需索引 |

## 代码回顾

```c#
// for
for (int i = 0; i < 10; i++)
{
    Console.WriteLine(i);
}

// while
int i = 0;
while (i < 10)
{
    Console.WriteLine(i);
    i++;
}

// do-while
int j = 0;
do
{
    Console.WriteLine(j);
    j++;
} while (j < 10);

// foreach
int[] nums = { 1, 2, 3, 4, 5 };
foreach (int num in nums)
{
    Console.WriteLine(num);
}
```

## 循环控制

| 关键字 | 作用 |
|--------|------|
| `break` | 立即终止整个循环 |
| `continue` | 跳过本次循环，进入下一次 |
| `return` | 结束整个方法 |
