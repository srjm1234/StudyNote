# 循环控制语句

在循环执行过程中，根据条件**主动干预循环的执行流程**，让程序更精准、高效地达到预期结果。C# 提供三个关键字：`continue`、`break`、`return`。

## 三者对比

| 关键字 | 作用 | 适用场景 |
|--------|------|----------|
| `continue` | **跳过当前迭代**，直接进入下一次循环 | 遍历时跳过特定数据（如跳过空值），但整体循环继续 |
| `break` | **彻底终止当前循环**，跳转到循环之后的代码 | 已找到目标结果即停（如查找数组中某个值） |
| `return` | **结束整个方法**，无论嵌套多少层循环都终止 | 在方法内通过循环找到结果后直接返回 |

**选择建议：**

- 只想**跳过本轮**、继续下一轮 → 用 `continue`
- 想**彻底退出循环**、继续执行循环之后的代码 → 用 `break`
- 想**直接结束整个方法**、不再执行方法内任何后续代码 → 用 `return`

## continue — 跳过本次循环

`continue` 后面的代码不执行，直接跳到下一次循环。

```csharp
for (int i = 1; i < 10; i++)
{
    if (i % 2 == 0) continue;  // 偶数跳过，不输出
    Console.WriteLine(i);      // 只输出奇数 1,3,5,7,9
}
```

## break — 终止当前循环

`break` 立即结束**当前这一层**循环（对多层循环只跳出最内层）。

```csharp
for (int i = 1; i < 10; i++)
{
    if (i == 5) break;   // 当 i=5 时跳出循环
    Console.WriteLine(i); // 输出 1,2,3,4
}
```

> 注意：`break` 只跳出所在的那一层循环，外层循环不受影响。

## return — 结束整个方法

`return` 无论嵌套多少层循环，都会直接结束整个方法。

```csharp
for (int i = 0; i < 10; i++)
{
    for (int j = 0; j < 10; j++)
    {
        if (j == 7)
        {
            Console.WriteLine("@@@@");
            return;   // 直接结束方法，两层循环全部终止
        }
    }
}
```
