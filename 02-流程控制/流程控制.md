# 流程控制

程序包含三种结构：**顺序结构**、**选择结构（分支）**、**循环结构**。本篇讲解选择结构（if / switch / goto）与异常处理。

## if 语句

### 单分支

```c#
if (布尔值或布尔表达式)
{
    // 条件为 true 时执行
}
```

### 双分支

```c#
if (布尔值或布尔表达式)
{
    // 条件为 true 时执行
}
else
{
    // 条件为 false 时执行
}
```

### 多分支

```c#
if (条件1)
{
    // 条件1成立时执行
}
else if (条件2)
{
    // 条件2成立时执行
}
else if (条件3)
{
    // 条件3成立时执行
}
else
{
    // 都不成立时执行
}
```

> 注意：条件之间有递进关系，一旦一个分支执行，其他分支不再执行。

### 分支嵌套

```c#
if (age > 0 && age < 123)
{
    if (age <= 12)
    {
        Console.WriteLine("儿童");
    }
    else if (age <= 18)
    {
        Console.WriteLine("青少年");
    }
    else if (age <= 40)
    {
        Console.WriteLine("青年");
    }
    else if (age <= 50)
    {
        Console.WriteLine("壮年");
    }
    else
    {
        Console.WriteLine("老年");
    }
}
else
{
    Console.WriteLine("年龄不合法");
}
```

> 注意：`if (0 > age < 123)` 是错误的，比较运算符不能连用，应写作 `age > 0 && age < 123`。

### 多个 if vs if-else

- **多个 if**：所有 if 都进行判断，条件成立都会执行
- **if-else**：一旦某个条件成立，不再对后面的 else if 进行判断

### 练习：三个数字比大小

```c#
int x = 200, y = 30, z = 20003;
int max = 0, min = 0;

if (x < y)
{
    if (y < z) { max = z; min = x; }
    else
    {
        max = y;
        if (x < z) { min = x; } else { min = z; }
    }
}
else
{
    if (x < z) { max = z; min = y; }
    else
    {
        max = x;
        if (z < y) { min = z; } else { min = y; }
    }
}

Console.WriteLine("最大值：" + max);
Console.WriteLine("最小值：" + min);
```

## switch 语句

类似 `if-else if`，适合判断同一个变量的不同取值。

```c#
switch (表达式)
{
    case value1:
        // 执行代码
        break;
    case value2:
        // 执行代码
        break;
    case value3:
        // 执行代码
        break;
    default:
        // 都不匹配时执行
        break;
}
```

## goto 语句

控制代码执行顺序，常用于输入校验后让用户重新输入。

```c#
// 1. 在合适的位置打一个标记
inputSex:
    Console.WriteLine("请输入性别");
    string sex = Console.ReadLine();
    if (sex == "男")
    {
        Console.WriteLine("爷们");
    }
    else if (sex == "女")
    {
        Console.WriteLine("不是爷们");
    }
    else
    {
        Console.WriteLine("输入错误,请重新输入");
        // 2. 使用 goto 跳转到标记位置
        goto inputSex;
    }
```

> 注意：goto 会降低代码可读性，尽量少用，一般仅用于校验并让用户重新输入。

## 分支练习题

1. 让用户在控制台输入一个数字，判断该数字是否是 3 的倍数，是输出「能被 3 整除」，否则输出「不能被 3 整除」
2. 让用户输入一个成绩，如果成绩大于 90 输出「优秀」
3. 让用户输入一个日期（如"星期一"），如果是星期六或星期日输出「是周末」，否则输出「不是周末」
4. 用户输入商品总价（double）和支付金额（double），计算找零。如果找零 ≥ 10 元输出「找零 xx 元，建议换成整钱」，否则输出「找零 xx 元」

### 练习题参考答案

```c#
// 1. 判断是否为3的倍数
Console.WriteLine("请输入一个数字：");
int num = Convert.ToInt32(Console.ReadLine());
if (num % 3 == 0)
    Console.WriteLine("能被3整除");
else
    Console.WriteLine("不能被3整除");

// 2. 成绩判断
Console.WriteLine("请输入成绩：");
int score = Convert.ToInt32(Console.ReadLine());
if (score > 90)
    Console.WriteLine("优秀");

// 3. 判断周末
Console.WriteLine("请输入日期（如星期一）：");
string day = Console.ReadLine();
if (day == "星期六" || day == "星期日")
    Console.WriteLine("是周末");
else
    Console.WriteLine("不是周末");

// 4. 找零计算
Console.WriteLine("请输入商品总价：");
double total = Convert.ToDouble(Console.ReadLine());
Console.WriteLine("请输入支付金额：");
double pay = Convert.ToDouble(Console.ReadLine());
double change = pay - total;
if (change >= 10)
    Console.WriteLine($"找零{change}元，建议换成整钱");
else
    Console.WriteLine($"找零{change}元");
```

## 异常处理（try-catch-finally）

程序运行时如果发生错误，默认会崩溃退出。`try-catch-finally` 结构可以捕获异常，让程序继续运行。

### 基本语法

```csharp
try
{
    // 可能发生异常的代码
}
catch (具体异常类型 ex)
{
    // 捕获并处理特定异常
}
catch (Exception ex)
{
    // 兜底：捕获所有未被前面 catch 处理的异常
}
finally
{
    // 不管有没有异常，都会执行
    // 通常用于资源清理（关闭文件、释放连接等）
}
```

### 示例

```csharp
try
{
    // 可能发生的异常
    int n = int.Parse("123.0");   // ❌ "123.0" 不是合法的整数格式
}
catch (FormatException ex)
{
    // 捕获特定异常类型
    Console.WriteLine("FormatException 发生错误：" + ex.Message);
}
catch (Exception ex)
{
    // 兜底行为 — 捕获所有其他异常
    Console.WriteLine("兜底：" + ex.Message);
}
finally
{
    // 不管有没有异常都会执行
    Console.WriteLine("不管有没有异常都会执行");
}
```

### 执行流程

```
try 块开始
  │
  ├─ 无异常 → 跳过 catch，执行 finally
  │
  ├─ 有 FormatException → 进入第一个 catch，然后执行 finally
  │
  └─ 有其他异常 → 进入第二个 catch（兜底），然后执行 finally
```

### 常用异常类型

| 异常类型 | 说明 | 示例 |
|----------|------|------|
| `FormatException` | 格式转换错误 | `int.Parse("abc")` |
| `DivideByZeroException` | 除零错误 | `10 / 0` |
| `NullReferenceException` | 空引用 | `null.ToString()` |
| `IndexOutOfRangeException` | 索引越界 | `arr[999]` |
| `Exception` | 所有异常的基类（兜底） | 捕获所有未处理的异常 |

### 最佳实践

1. **先捕获具体异常，再捕获通用异常** — `catch (FormatException)` 在前，`catch (Exception)` 在后
2. **finally 用于资源清理** — 关闭文件流、数据库连接等
3. **不要吞掉异常** — 至少记录 `ex.Message`，方便排查问题
4. **尽量缩小 try 的范围** — 只包裹可能出错的代码，不要包整个方法
