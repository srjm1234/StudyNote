# String 方法补充

> 本笔记的内容（Insert / IsNullOrEmpty / Join / Replace / ToUpper / ToLower / Remove / Split / ToCharArray / 自定义工具方法）已完整合并至 [[06-字符串/String常用方法]]，本文仅作索引跳转。

## 原内容目录

- `Insert()` — 在指定索引位置插入字符串
- `IsNullOrEmpty()` — 判断字符串是否为 null 或空
- `Join()` — 按指定分隔符拼接数组为字符串
- `Replace()` — 替换字符串中的指定内容
- `ToUpper() / ToLower()` — 大小写转换
- `Remove()` — 删除指定位置的字符
- `Split()` — 按指定字符分割字符串为数组
- `ToCharArray()` — 将字符串转换为字符数组
- 自定义字符串工具方法（Rate.StrIndex）
