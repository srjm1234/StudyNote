# Visual Studio 常用快捷键清单

## 编辑操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 |
| `Ctrl + X` | 剪切 |
| `Ctrl + C` | 复制 |
| `Ctrl + V` | 粘贴 |
| `Ctrl + Shift + V` | 粘贴为环形格式 |
| `Ctrl + Shift + L` | 删除当前行 |
| `Ctrl + L` | 剪切当前行 |
| `Ctrl + Shift + ↑ / ↓` | 移动当前行上下 |
| `Alt + Shift + ↑ / ↓` | 复制当前行上下 |
| `Ctrl + D` | 复制当前行 |
| `Ctrl + Delete` | 删除光标到词尾 |
| `Ctrl + Backspace` | 删除光标到词首 |
| `Ctrl + /` | 注释/取消注释当前行 |
| `Ctrl + K, Ctrl + C` | 注释选中内容 |
| `Ctrl + K, Ctrl + U` | 取消注释选中内容 |
| `Ctrl + S` | 保存文件 |
| `Ctrl + Shift + S` | 保存所有文件 |
| `Ctrl + F` | 查找 |
| `Ctrl + H` | 替换 |
| `Ctrl + Shift + F` | 在文件中查找 |
| `Ctrl + Shift + H` | 在文件中替换 |
| `Ctrl + .` | 快速操作和重构 |
| `Alt + Enter` | 显示快速操作 |
| `Ctrl + R, Ctrl + G` | 删除无用引用 |
| `Ctrl + T` / `Ctrl + ,` | 转到所有 |
| `Ctrl + ;` | 快速查找符号 |
| `Ctrl + Shift + Alt + L` | 格式化文档 |

## 导航

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Tab` | 切换活动窗口 |
| `Ctrl + -` | 向后导航 |
| `Ctrl + Shift + -` | 向前导航 |
| `Ctrl + G` | 转到行号 |
| `Ctrl + ]` | 匹配大括号 |
| `Ctrl + M, Ctrl + M` | 折叠/展开当前代码块 |
| `Ctrl + M, Ctrl + L` | 展开/折叠所有代码块 |
| `Ctrl + K, Ctrl + W` | 关闭当前标签页 |
| `F12` | 转到定义 |
| `Alt + F12` | 查看定义（不切换上下文） |
| `Ctrl + F12` | 转到实现 |
| `Ctrl + Shift + F12` | 查看所有引用 |
| `Shift + F12` | 查找所有引用 |
| `Ctrl + -` | 后退 |
| `Ctrl + Shift + -` | 前进 |
