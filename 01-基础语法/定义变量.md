# 变量

## 什么是变量

变量是内存中的一块存储空间，用于存储程序运行过程中的数据。可以随时读取或修改其中的值。

## 定义变量

1. 变量需要**声明数据类型**才能定义。
2. 可先定义变量再赋值。
3. 变量允许**改变值**。
4. 变量存在于内存中的一块空间。

## 示例

```c#
// 声明并初始化
int age = 18;

// 先声明，再赋值
string name;
name = "张三";

// 修改变量的值
age = 20;  // age 现在是 20
```

## 变量的命名

- 遵循 C# 标识符命名规则（见 [[01-基础语法/C#基础]]）
- 局部变量建议使用**小驼峰命名法**（camelCase）：`studentName`、`maxNum`

## 变量的三种输出方式

```c#
int num = 60;
Console.WriteLine("218教室有" + num + "人");   // 方式一：+ 拼接
Console.WriteLine("218教室有{0}人", num);      // 方式二：占位符
Console.WriteLine($"218教室有{num}人");         // 方式三：$ 插值（推荐）
```
