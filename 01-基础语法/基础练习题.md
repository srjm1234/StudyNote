# 基础练习题

## 基础题

定义一个整数类型变量，存储数字 `100`；定义一个字符类型变量，存储字符 `1`、`x`、`牛`；定义一个字符串类型变量，存储 `100`、`牛`、`你好牛啊`。

```c#
int a1 = 100;
char b1 = '1';
char c1 = 'x';
char d1 = '牛';
string e1 = "牛";
string f1 = "你好牛啊";
```

## 普通题

**1.** 定义一个整数类型的变量，存储班级的人数，比如 `60`，然后控制台输出变量的值。

**2.** 定义一个整数类型的变量 `a`，值是 `6`；定义一个字符类型变量 `b` 存储 `6` 这个字符；定义一个字符串类型的变量 `c` 存储 `6` 这个字符串，然后分别输出 `a`、`b`、`c` 变量的值。

**3.** 定义一个整数类型的变量，存储班级的人数，比如 `60`，然后在控制台输出：`218教室有60人`，使用三种方式输出：

- 第一种使用 `+` 拼接
- 第二种使用占位符 `{0}`
- 第三种使用 `$` 插值

```c#
Console.WriteLine("普通题：");
int sum = 60;
Console.WriteLine("1.  值:{0}，类型:{1}", sum, sum.GetType());

int a = 6;
char b = '6';
string c = "6";
Console.WriteLine("2.  a:{0}，b:{1}，c:{2}", a, b, c);

int num = 60;
Console.WriteLine("3. 218教室有" + num + "人");
Console.WriteLine("   218教室有{0}人", num);
Console.WriteLine($"   218教室有{num}人");
```

**思考题：** 能不能把 `218教室有` 存储到字符串，`人` 存储到字符串，然后和 `60` 这个整数类型变量拼接出来结果：`218教室有60人`

```c#
string str1 = "218教室有";
string str2 = "人";
Console.WriteLine("思考：" + str1 + num + str2);
```

## 扩展思考

思考数据类型为什么分为那么多种？

1. **类型安全** — 编译时检查，减少运行时错误
2. **效率高** — 不同场景使用不同大小的类型，提升性能
3. **节省存储空间** — 避免不必要的内存开销

预习：所有的整数数据类型有哪些？有什么区别？什么时候用哪一种？
