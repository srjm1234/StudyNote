# Math 数学运算

`Math` 是 C# 内置的静态类，提供常用的数学运算方法。调用格式统一为 `Math.方法名(参数)`，无需创建实例。

## 常用方法速查

| 方法 | 功能 | 示例 | 结果 |
|------|------|------|------|
| `Math.Abs(x)` | 求绝对值 | `Math.Abs(-10)` | 10 |
| `Math.Sqrt(x)` | 开平方根 | `Math.Sqrt(9)` | 3 |
| `Math.Round(x)` | 四舍五入 | `Math.Round(5.5)` | 6 |
| `Math.Floor(x)` | 向下取整 | `Math.Floor(5.9)` | 5 |
| `Math.Ceiling(x)` | 向上取整 | `Math.Ceiling(5.9)` | 6 |
| `Math.Max(a, b)` | 求最大值 | `Math.Max(10, 20)` | 20 |
| `Math.Min(a, b)` | 求最小值 | `Math.Min(10, 20)` | 10 |
| `Math.Pow(x, y)` | 幂运算（x 的 y 次方） | `Math.Pow(3, 3)` | 27 |

## 代码示例

```csharp
// 求绝对值：把要取绝对值的数字写到 () 中
Console.WriteLine(Math.Abs(-10));   // 10

// 开平方根：开平方
Console.WriteLine(Math.Sqrt(9));    // 3

// 四舍五入
Console.WriteLine(Math.Round(5.5)); // 6

// 向下取整
Console.WriteLine(Math.Floor(5.9)); // 5

// 向上取整
Console.WriteLine(Math.Ceiling(5.9)); // 6

// 最大值 / 最小值：参数1 = 第一个数字，参数2 = 第二个数字
Console.WriteLine(Math.Max(10, 20)); // 20
Console.WriteLine(Math.Min(10, 20)); // 10

// 幂运算：3^2 = 9（3 的 2 次方）
Console.WriteLine(Math.Pow(3, 2));  // 9

// 圆周率 π（属性，无需括号）
Console.WriteLine(Math.PI);         // 3.14159265358979
```

## 类型最大/最小值与无穷大

```csharp
// 获取某个类型的最大值 / 最小值（属性，非方法）
Console.WriteLine(int.MaxValue);            // 2147483647
Console.WriteLine(int.MinValue);            // -2147483648
Console.WriteLine(double.MaxValue);
Console.WriteLine(double.MinValue);

// 无穷大（double 类型）
Console.WriteLine(double.NegativeInfinity); // -∞
Console.WriteLine(double.PositiveInfinity); // ∞
```
