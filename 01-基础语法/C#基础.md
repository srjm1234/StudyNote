# C# 基础

## C# 是什么

C# 是一门**强类型语言**，由微软开发，运行在 .NET 平台上。程序中的每个变量都必须声明明确的类型，编译器在编译阶段就会做类型检查，从而减少运行时错误。

## .NET Framework

给编程语言提供的一个可运行的环境、一个平台、一个框架。

### 组成部分

- **CLR**（Common Language Runtime）：公共语言运行库，负责代码的执行、内存管理、安全等。
- **FCL**（Framework Class Library）：框架类库，提供大量常用功能和基础类。

> 通俗理解：CLR 是"运行引擎"，FCL 是"工具箱"，两者合起来构成了 .NET 运行环境。

## C# 程序结构

一个最简单的 C# 程序包含以下结构：

```c#
using System; // 引用已有的命名空间

namespace Mingzi // 声明一个命名空间
{
    class Program // 定义一个类
    {
        // Main 是程序入口，static 和 void 都是修饰 Main 的关键字
        static void Main(string[] args)
        {
            Console.Write("hello world");
        }
    }
}
```

**各部分作用：**

| 关键字 | 作用 |
|--------|------|
| `using` | 引用其他命名空间，引入后可直接使用其中的类型 |
| `namespace` | 声明命名空间，用于分类组织代码 |
| `class` | 定义一个类 |
| `static` | 静态方法，无需实例化即可调用 |
| `void` | 无返回值 |
| `Main` | 程序入口方法，每个程序有且仅有一个 |

## C# 标识符命名规则

标识符是分配给变量、方法、命名空间等程序元素的名称。

**命名规则：**

1. 必须以**字母**或**下划线**（`_`）开头，**不能**以数字开头。
2. 可包含字母、数字、下划线。
3. 不能使用 C# 关键字。
4. 具有唯一性，**区分大小写**。

**命名约定：**

| 命名对象 | 约定 | 示例 |
|----------|------|------|
| 类、方法、属性 | PascalCase（大驼峰） | `StudentInfo`、`GetMax` |
| 局部变量、参数 | camelCase（小驼峰） | `studentName`、`maxNum` |
| 常量 | 全部大写或 PascalCase | `MAX_COUNT` |
