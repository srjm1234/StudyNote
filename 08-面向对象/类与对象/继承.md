# 继承

> 来源：`D:\study\C#1\stu0724\继承`

继承是面向对象的三大特性之一（封装、继承、多态）。它允许一个类（子类/派生类）获得另一个类（父类/基类）的属性和方法，实现代码复用。

## 基本语法

```csharp
// 父类（基类）
class People
{
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }
}

// 子类（派生类）— 继承 People，自动获得 Id、Name、Age
class Student : People
{
    public int StuId { get; set; }
}
```

## 关键规则

| 规则 | 说明 |
|------|------|
| **单继承** | 一个类只能继承一个父类，不能同时继承多个类 |
| **多层继承** | 子类可以再被其他类继承，形成继承链 |
| **基类与派生类不是绝对的** | 相对于 Student，People 是基类；相对于 SmallStu，Student 是基类 |

## 多层继承示例

```csharp
class People      // 第一层基类
{
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }
}

class Student : People    // 第二层：继承 People
{
    public int StuId { get; set; }
}

class SmallStu : Student  // 第三层：继承 Student（间接继承 People）
{
    public int Fumu { get; set; }
}
// SmallStu 可以访问 Id、Name、Age（来自 People）、StuId（来自 Student）、Fumu（自身）
```
