# 类与对象（预习）

## 什么是类

C# 中需要用**类**这个模板来创建对象。类描述了一组对象的**共同属性**（字段/属性）和**行为**（方法）。

**举例：**

1. 我是一个怪兽（**类名**），我叫 xx（**对象名**），身高 3 米（**对象身高**，属性），喜欢大叫（**对象行为**）、跑步（**对象行为**）。
2. 我是一个玩家（**类名**），我叫 xx（**对象名**），我有一套装备（装备数组对象：圣衣、重剑），喜欢攻击小怪兽和锻造名刀（**对象行为**）。

## 定义类

定义一个类需要用到关键字 `class` 加一对大括号：

```csharp
using System;

namespace Class
{
    internal class Program // 主类
    {
        static void Main(string[] args)
        {
            Monster m1 = new Monster();
            Console.WriteLine(m1.name);
            Console.WriteLine(m1.height);
            m1.Shout();
            m1.run();

            Monster m2 = new Monster();
            m2.name = "小臂噶";
            m2.height = 100;
            Console.WriteLine(m2.name);
            Console.WriteLine(m2.height);
        }
    }

    // 定义类
    class Monster
    {
        // 类的属性（身高、名字）— 字段
        public int height = 300;
        public string name = "哞哞";

        // 定义类的行为（方法）
        public void Shout()
        {
            Console.WriteLine("我是怪物");
        }
        public void run()
        {
            Console.WriteLine("溜了溜了");
        }
    }
}
```

## 对象创建细节

- 在实例化对象时，程序会自动为类中的字段进行初始化，针对不同类型的字段赋予不同的默认值：

| 字段类型 | 初始值 | 字段类型 | 初始值 |
|---------|--------|---------|--------|
| byte | 0 | double | 0.0D |
| short | 0 | char | '\0' |
| int | 0 | bool | false |
| long | 0L | 引用类型 | null |
| decimal | 0.0M | | |
